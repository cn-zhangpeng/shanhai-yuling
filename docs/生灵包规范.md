# 山海遇灵 · 生灵包规范（v1 + v2 清单）

一个生灵 = 一个目录。加一只新的萌宠不用改代码：建目录、丢图、扫描，设置页的下拉框里就多一项。

## 1. 目录放哪

只有**一个**根：`%APPDATA%\山海遇灵\creatures\`，设置页里叫「生灵目录」。一个文件夹 = 一只生灵，冉冉也在里面。

| 位置 | 用途 |
| --- | --- |
| `%APPDATA%\山海遇灵\creatures\冉冉\` | 内置这只。首次启动从程序目录的 `assets\` 复制一份种子过来，之后和用户自定义的完全同级、直接可改 |
| `%APPDATA%\山海遇灵\creatures\用户自定义1\`（2、3…） | 设置页「复制为新形象」生成，或自己新建文件夹 |
| `<安装目录>\resources\app\assets\` | **原始素材种子（只读）**：留档给素材流程用，运行时不再读；改这里不会影响桌面上的她 |

设置页 →「形象」→「打开生灵目录」会直接打开这个根。

## 2. 目录结构

```
生灵目录\
  冉冉\                      ← 目录名 = 生灵 ID（中文也能用）
    creature.json            ← 可选。不写也能用，写了能改名字/窗口高度/伴生灵
    frames\                  ← 图放这里
      base.png
      blink.png
      walkA.png
      ...
    companion\               ← 可选，伴生灵雪碧图
      ant.png
    lines.json               ← 可选，常用语（也可以在设置页里加）
  用户自定义1\                ← 同一套结构
  说明.txt                   ← 纯文字目录说明
```

只有一张 `base.png` 也能用：能显示、能拖、能点、能眨眼（有 blink 的话），
走/跳/看手机这些动作会自动禁用并在菜单里写明原因——这是**降级**，不是报错。

## 3. 帧名表（文件名就是语义）

`frames\` 里的文件名按 `_`、`-` 切成词，词里出现下面的名字就认领该帧，不区分大小写。
所以 `base.png`、`小兔_base_2x.png`、`rabbit-base.png` 都能认领 `base`。

| 语义 | 帧名 | 必需 | 说明 |
| --- | --- | --- | --- |
| 坐姿待机 | `base` | **必需** | 初始姿态，没有它整只生灵显示不出来 |
| 眨眼 | `blink` | 可选 | 同一个姿态只闭眼，硬切不做淡入 |
| 说话 | `talk` | 可选 | 嘴型张开 |
| 笑 | `smile` | 可选 | 月牙眼 |
| 转头 | `turn` / `turnL` | 可选 | 左/右各一张 |
| 挥手 | `wave` | 可选 | 主动打招呼时用 |
| 空手坐姿 | `noant` | 可选 | 伴生灵在地上时替换坐姿帧，避免"怀里一只、地上又一只" |
| 站姿 | `stand` | 走动必需 | |
| 走帧 | `walkA` `walkB` `walkP1` `walkP2` | 走动必需 | 四姿态循环：接触左 / 过渡 / 接触右 / 过渡 |
| 蹲着玩手机 | `phone` | 看手机必需 | |
| 跳绳 | `ropeAir` `ropeLand` | 跳绳必需 | 腾空 / 落地 |
| 放下伴生灵后的小动作 | `ntTurn` `ntTurnL` `ntSmile` `ntWave` `ntBlink` | 可选 | 名字去掉 `nt` 对应的就是原姿态 |
| 晃脚 / 抚帽边 | `footSwing` `handEar` | 可选 | 坐着时的"活气" |
| 同上（空手版） | `ntFootSwing` `ntHandEar` | 可选 | |

## 4. 图怎么画

- **透明底 PNG**，四角 alpha 必须是 0。带底色的一块会跟着贴到桌面上。
- **同一套图宽高一致**。不一致会在切帧时跳尺寸。
- **脚底基线对齐**：站姿/走帧的脚必须在同一条水平线上，偏差超过画布高度 2% 就会看着悬空或陷进桌面。
- **朝向统一画左边**。程序往右走时整只镜像；画成朝右就是倒着走。
- 头顶位置**不用手量**：主进程扫 alpha 自动算，气泡会贴着头顶。写了 `headTop` 才覆盖。
- 尺寸建议：短边 ≥ 700 px，透明画布，人物摆在画布中下 2/3。

## 5. creature.json（可选）

```json
{
  "schemaVersion": 1,
  "id": "xiaotu",
  "displayName": "小兔",
  "window": { "petHeight": 600 },
  "frames": {
    "base": { "file": "frames/base.png", "headTop": 268, "sit": true },
    "stand": { "file": "frames/stand.png", "headTop": 221 }
  },
  "companion": { "file": "companion/ant.png", "frames": 9, "cellW": 340, "cellH": 332, "contentW": 265 },
  "lines": "lines.json",
  "behavior": {
    "mode": "quiet",
    "modes": { "quiet": { "greetPerMin": 0.15 }, "lively": { "greetPerMin": 0.35 } }
  }
}
```

| 字段 | 作用 |
| --- | --- |
| `displayName` | 下拉框和设置页显示的名字；不写就用目录名 |
| `window.petHeight` | 显示高度（CSS px）。窗口宽高按这个 + `base` 的宽高比自动算 |
| `frames.<name>.file` | 显式指定文件（文件名不合规则时用） |
| `frames.<name>.headTop` | 气泡锚点，单位是**图片像素**（原图里内容顶边的行号）。不写就自动量 |
| `frames.<name>.sit` | 是否坐姿帧。不写按规则推断：`stand/walk*/phone/rope*` 以外都算坐姿 |
| `frames.<name>.noAnt` | 这张坐姿帧对应的空手版帧名。不写按 `nt` 前缀推断 |
| `companion.file / frames / cellW / cellH` | 伴生灵雪碧图。整段删掉 = 这只生灵没有伴生灵 |
| `lines` | 台词文件名，默认 `lines.json` |
| `behavior.modes.<档位>.greetPerMin` | 每分钟主动开口概率 |

## 6. 交图前怎么核对（不用装 Python）

打开桌宠 → 右键 → 设置 → **形象** 页，那里会直接告诉你：

- **帧 25 / 25（齐了）** 或 **缺：blink、walkA …** —— 缺哪些帧一目了然；
- **图片尺寸** `900 × 1360（一套图一致）`，不一致会标红并列出是哪几张；
- **可用动作** 走动 / 跳绳 / 玩手机 / 陪伴生灵 各自是 ✓ 还是 ✗。

三项都正常就可以直接用了。**朝向、透明底、脚底基线程序看不出来**，这三条只能按第 4 节自己把关。

如果你（或负责画图的人）机器上有 Python，可以批量核对：

```powershell
python tools\check_creature.py "C:\Users\你\AppData\Roaming\山海遇灵\creatures\用户自定义2"
python tools\check_creature.py --scan            # 生灵目录下所有形象一次扫完
python tools\check_creature.py --init "...\creatures\用户自定义2"   # 生成空骨架
python tools\check_creature.py <目录> --write-anchor        # 把量出来的 headTop 写回 creature.json
```

它查的是：有没有 `base`、文件名能不能认领、是否透明底、宽高是否一致、脚底基线偏差、伴生灵切帧整除。
退出码 0 = 能用，1 = 有错误。这是可选的辅助手段，日常加一只生灵不需要它。

### 6.1 首次启动会给你什么

生灵目录里会落两样：

1. `说明.txt` —— 纯文字，讲目录怎么摆、图要多大多宽、透明底这些。
2. `冉冉\` —— 从程序目录 `assets\` 复制的一份**种子形象**（25 帧 + 伴生灵雪碧图 + 图标 + `lines.json` + `creature.json`）。之后她就和用户自定义的完全同级：素材页可以直接逐帧替换，点「复制为新形象」会生成 `用户自定义1\`、`用户自定义2\`…

不会塞“拿图标凑的假角色”：那版带背景、只到胸口，看着像坏图，早就去掉了。

## 7. 降级规则（用户视角）

| 缺什么 | 表现 |
| --- | --- |
| 没有 `base` | 下拉框里灰掉，标注「损坏」 |
| 只有 `base` | 标注「静态：只有一张图」，走动/跳绳/看手机菜单项禁用并写明原因 |
| 没有伴生灵 | 「陪小蚂蚁玩」禁用；台词库里 `category: "ant"` 的句子不出现 |
| 没有 `stand` + 4 走帧 | 走动场景不演，自主日程里也不会抽到它 |
| 没有 `ropeAir/ropeLand` | 跳绳禁用 |
| 没有 `phone` | 看手机禁用 |

## 8. 三条硬规矩

1. **儿童肖像**：真实未成年人的图、分层 PSD 不进公开仓库、不发第三方。
2. **别复用第三方 IP 的具体特征**（布偶缝线、金冠、专属挂件这类），按自己的角色重画。
3. 换图后不用重启、不用清缓存：主进程按文件 mtime 生成 URL，Chromium 不会拿旧图。
   （如果是让别人替换同名文件，程序启动时也会清一次缓存。）

## 9. 清单 v2：帧轨道 / 序列 / 相位（可选，推荐）

v1 里"眨眼 150ms、走一步 200ms、跳绳 185ms、坐姿小动作随机一个"这些节拍都写死在
`desk-pet.html` 里，换一只节奏不同的形象只能改代码。v2 把节拍和顺序收进 `creature.json`：

```json
{
  "schemaVersion": 2,
  "tracks": {
    "idle":  { "frames": ["base"], "durations": [600], "loop": true },
    "blink": { "frames": ["blink"], "durations": [150] },
    "turn":  { "frames": ["turn"], "durations": [720], "fallback": "idle" },
    "walk":  { "frames": ["walkA", "walkP1", "walkB", "walkP2"],
               "durations": [200, 200, 200, 200], "loop": true },
    "rope":  { "frames": ["ropeAir", "ropeLand"], "durations": [170, 170], "loop": true }
  },
  "sequences": {
    "idle":  ["turn", "idle", "smile"],
    "greet": ["wave", "talk"]
  },
  "phases": {
    "blink": "blink", "greet": "wave", "walk": "walk", "rope": "rope"
  }
}
```

| 字段 | 作用 |
| --- | --- |
| `tracks.<名>.frames` | 这条轨道依次显示的帧名（必须是第 3 节里认得出的帧） |
| `durations` | 每帧停留毫秒数；可以比 `frames` 短，缺的用最后一个补齐 |
| `loop` | `true` 时播完回到第一帧一直循环（待机、走路、跳绳用） |
| `fallback` | 不循环的轨道播完后接着播哪条轨道；不写就停在最后一帧 |
| `ambient` | 只作标记，表示这条轨道适合进"坐着时的小动作"随机池 |
| `sequences.<名>` | 一组按顺序播的轨道。序列里的循环轨道只播一轮（比如"转头→回坐姿→笑"） |
| `phases.<相位>` | 相位 → 轨道名：`blink`（眨眼）、`greet`（打招呼）、`walk`、`rope`、`phone`、`stand` |

**不写 `tracks` 的 v1 清单照旧能用**：程序按现有帧自动合成一套默认轨道
（待机 600ms、眨眼 150、转头 720、笑 1500、说话 600、挥手 1100、晃脚/抚帽边 1200、
站姿 430、看手机 1000、走路 4×200 循环、跳绳 2×185 循环），行为与旧版一致。

校验是 **fail-closed** 的：结构坏掉、帧全不存在的轨道直接丢弃（错误）；部分缺帧、
时长不是正数、`fallback` 悬空或成环、引用了不存在的轨道/序列/相位，都会修掉并记一条
警告。设置页"帧轨道"一行会显示轨道数与错误/警告数，鼠标悬停看明细；命令行核对：

```powershell
node desktop-shell\tools\validate-creature.js "C:\Users\你\AppData\Roaming\山海遇灵\creatures\用户自定义2"
```

退出码 0 = 没有错误，1 = 有错误诊断。`durations` 只改"什么时候换下一张帧"，
不改渲染：淡入/硬切仍按帧名自动选（眨眼淡入、换姿态硬切），鼠标穿透上报也不受影响。
