生灵目录怎么摆（不用改代码，也不用装 Python）

所有形象都住在同一个根下，一个文件夹 = 一只萌宠，文件夹名就是它的名字。冉冉也在里面（首次启动从程序目录的原始素材复制一份种子），和用户自定义的完全同级：

生灵目录\
  冉冉\
  用户自定义1\
  用户自定义2\

  1. 改现成的：设置页 → 素材 → 找到动作帧点「替换」。
  2. 另起一只：设置页 → 素材 →「复制为新形象」（生成 用户自定义N），或点上面「打开生灵目录」自己新建一个文件夹。
  3. 自己建的话：文件夹里建 frames 子目录，把图片丢进去，文件名直接用下面这些帧名；回本页点「重新扫描」，下拉框里就多一项。

最少只要一张 base.png（坐姿）：能显示、能拖、能点。走 / 跳 / 看手机会自动禁用并写明原因，这不算坏，只是这套图没那些动作。

图片要求

  • 透明底 PNG：四角必须透明，不要白底、不要画背景。带底色的图会连背景一起贴到桌面上。
  • 一套图宽高完全一致：—
  • 脚踩同一条水平线：站姿和 4 张走路帧的脚底要对齐，否则走路时整只会浮空或陷进桌面。
  • 统一朝画面左边画：往右走时程序整体镜像，画成朝右就是倒着走。
  • 头顶不用量：气泡锚点由程序扫透明像素自动算，写 creature.json 的 headTop 才覆盖。

可选：文件夹里放 creature.json 可以改显示名 / 窗口高度 / 伴生灵；放 lines.json 写台词（也可以直接在「常用语」页改）。

给维护者：批量自检脚本 tools\check_creature.py 需要 Python，普通使用不用跑它——缺哪些帧、尺寸对不对，本页这里都会直接标出来。清单里写了帧轨道（v2）时，也可以直接 node desktop-shell\tools\validate-creature.js <生灵目录> 核对轨道/序列/相位与诊断。

想留一份底再改？点「复制为新形象」，把现在这只整体复制成 用户自定义N 并切过去——两只从此各改各的，互不影响。

一行一个动作帧。上传的图存进这只生灵目录的 frames\<帧名>.png，并写进 creature.json 做显式绑定；上传即生效，不用重启。图不对（尺寸不符、四角不透明）会被直接挡下来，不会写进去。
